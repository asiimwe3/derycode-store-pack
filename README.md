# DeryCode store submission pack

Everything needed to publish every DeryCode app to the free app stores, in one place.

- `STORES.md` — the checklist, store by store, including what each one requires and what is already done
- `apps/<app>/listing.md` — copy-paste listing text, permissions, checksums
- `apps/<app>/icon-512.png` — store icon
- `apps/<app>/fastlane/` — metadata for F-Droid and IzzyOnDroid
- `desktop/school-report-maker/` — winget, Chocolatey and Scoop manifests
- `artifacts/` — the exact APKs and MSI these listings describe

Maintained by DeryCode Technologies, Kyenjojo, Uganda. https://derycode.online
